## Honest deviation note

The assignment asks for ~5h train / ~1h val per language. Measured pool: 9.6h across 2 speaker(s) (durations measured from decoded audio; the HF dataset card's hour counts were found to be inaccurate).
No single speaker in this dataset reaches ~6h, so this model trains **multi-speaker with learned speaker embeddings** (`multi_speaker: true`), keeping ~5h/~1h as the data-volume target. This is documented here and in the technical report rather than hidden.
